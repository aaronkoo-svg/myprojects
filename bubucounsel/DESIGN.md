# bubucounsel 디자인 시스템

Apple 스타일 DESIGN.md(`docs/reference/apple-DESIGN.md`)를 **토스 미니앱·모바일 한 손 사용**에 맞게 옮기고, v2에서 채팅 중심·캐릭터 방향으로 바꾼 문서입니다. 시안: [디자인 캔버스](https://claude.ai/artifact/MPUVBAgcZms4XYcSDDRwPc)
화면을 만들 때는 이 문서를 기준으로 합니다.

## 1. 원칙 (v2: 채팅 중심)

1. **에이전트가 주인공.** 앱은 캐릭터 "투닥이"와 나누는 대화다. 캡처 분석, 답장 다듬기, 털어놓기가 모두 한 입력창에서 시작한다.
2. **보송한 캐릭터와 파스텔.** 펠트 질감 캐릭터(파랑·보라·주황·초록)가 화면의 감정을 만든다. 파스텔 그라데이션은 캐릭터가 있는 카드 바탕에만 쓰고, 글과 버튼 주변은 흰색으로 둔다.
3. **포인트 색은 하나.** 누를 수 있는 것과 선택된 것은 모두 `--primary`(#4361E8). 캐릭터 색은 장식이지 상태 표시가 아니다.
4. **AI 결과는 카드로.** 판정·보낼 문장·짚어 볼 말은 채팅 안의 카드로 보여 주고, 다음 행동은 카드 아래 이어 묻기 버튼으로 제안한다.
5. **편들지 않는 톤.** 빨강·초록으로 사람을 칠하지 않는다. 의미색은 *말(발화)* 에만 붙인다.

## 2. 토스 미니앱 제약 (디자인에 영향을 주는 것)

| 제약 | 적용 |
| --- | --- |
| 라이트 모드만 허용 | Apple 원본의 검은 타일(`#272729` 등)은 쓰지 않는다. 흰색·파치먼트 두 가지 바탕만 번갈아 쓴다. |
| 상단 내비게이션 바는 토스 공통 바 사용 | 자체 헤더·자체 뒤로가기 버튼을 만들지 않는다. 화면 제목은 본문 첫 줄의 큰 제목으로 표현. |
| 탭바는 토스 플로팅 탭바 형태, 2~5개 | 탭 3개(대화·기록·연습). 화면 하단에 떠 있는 알약 형태. 대화 화면에서는 탭바 대신 입력창. |
| 진입 즉시 바텀시트 금지 | AI 고지는 홈 입력창 아래 작은 글로, 권한은 첨부 버튼을 눌렀을 때. |
| 핀치 줌 비활성화 | 스크린샷 확대는 탭해서 전체 화면 보기로 제공. |
| 생성형 AI 결과 표시 의무 | 투닥이의 모든 말에 이름과 `AI` 표시, 분석 카드에는 `AI 분석` 배지. |

## 3. 색

값은 `app/src/styles/tokens.css`에 있다.

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| `--primary` | #4361E8 | 버튼, 선택된 탭, 내 말풍선 |
| `--ink` / `--ink-70` / `--ink-60` / `--ink-48` | #1D1D1F / #3D4250 / #5F6370 / #6E6E73 | 글자 (모두 흰 바탕 4.5:1 이상) |
| `--surface` / `--surface-chip` | #F5F6FA / #F2F4F8 | 목록 카드, 칩, 입력칸 |
| `--wash-blue` 등 | 파스텔 방사형 그라데이션 | 캐릭터가 있는 카드 바탕에만 |
| `--tone-*` | 초록·주황·빨강 옅은 바탕 + 진한 글자 | 짚어 볼 말 표시에만 |

- 나/상대 구분은 색이 아니라 **정렬(오른쪽/왼쪽)** 과 이름표로 한다.
- 캐릭터 색: 투닥이(파랑) = 대화, 보라 = 기록·돌아보기, 초록 = 답장 다듬기, 주황 = 실전 연습.

## 4. 글꼴

**Pretendard Variable 하나만 쓴다.** (SIL OFL 1.1, 무료·상업 이용 가능, npm `pretendard`)
SF Pro는 Apple 기기 밖에서 쓸 수 없는 라이선스라 쓰지 않는다. Pretendard는 SF Pro와 Apple SD 산돌고딕 Neo의 비례를 따라 만든 글꼴이라 한글·영문·숫자를 섞어도 Apple 인상이 유지된다.

```css
font-family: "Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont,
             system-ui, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif;
font-feature-settings: "ss05", "tnum";  /* 숫자 폭 고정 */
word-break: keep-all;                   /* 한글 단어 중간 줄바꿈 방지 */
```

- 다이나믹 서브셋(woff2)으로 번들에 넣어 자체 호스팅한다. 외부 CDN에 의존하지 않는다.
- 감정이 실리는 인용문에만 쓸 보조 명조체(마루 부리, OFL)는 1차 범위에서 넣지 않는다. 글꼴이 하나일 때 더 고급스럽다.

| 역할 | 크기 / 줄높이 | 굵기 | 자간 |
| --- | --- | --- | --- |
| display (결과 한 줄 요약) | 32 / 1.15 | 700 | -0.02em |
| title-1 (화면 제목) | 26 / 1.2 | 700 | -0.02em |
| title-2 (섹션 제목) | 20 / 1.3 | 600 | -0.015em |
| body (본문) | 17 / 1.55 | 400 | -0.01em |
| body-strong | 17 / 1.55 | 600 | -0.01em |
| callout (말풍선, 추천 문장) | 16 / 1.5 | 500 | -0.01em |
| caption | 14 / 1.45 | 400 | -0.005em |
| fine-print (고지 문구) | 12 / 1.4 | 400 | 0 |

- 본문 최소 16px, 고지 문구도 12px 아래로 내리지 않는다.
- 굵기는 400·500·600·700 네 가지만.

## 5. 간격·모양

- 간격 단위: 4 · 8 · 12 · 16 · 20 · 24 · 32. 화면 좌우 여백 16px.
- 모서리: 큰 캐릭터 카드 30~32px, 카드 22px, 칩·입력칸 14px, 버튼·탭바·말풍선 알약.
- 그림자: 채팅 카드는 1px 선 + 아주 옅은 그림자(`--shadow-card`), 떠 있는 탭바만 `--shadow-float`.

## 6. 컴포넌트

- **투닥이(캐릭터)**: `components/Mascot.tsx`. 큰 그림은 펠트 질감·볼터치·그림자, 채팅 아바타(36px)는 질감 없이 단순하게.
- **입력창(Composer)**: 사진 첨부 + 글 입력 + 보내기. 홈에서는 흰 알약(캐릭터 카드 안), 대화에서는 화면 아래 고정 바. 사진을 붙이면 위에 썸네일 트레이가 생기고 안내 문구가 "어떤 상황이었는지 적어도 좋아요"로 바뀐다.
- **말풍선**: 내 말은 오른쪽 파란 알약(아래 오른쪽 모서리만 각지게), 투닥이 말은 왼쪽 흰 카드(위 왼쪽 모서리만 각지게).
- **판정 카드**: `AI 분석` 배지 → 한 줄 요약(19px/700) → 나·상대 비율 막대 → 이유 → `결과가 이상해요`.
- **보낼 문장 카드**: 연보라 바탕, 부드럽게/솔직하게/짧게 전환, `복사하기` + `다르게 써 줘`.
- **이어 묻기 버튼**: 흰 바탕 파란 글자 알약, 가로 스크롤. 왜 그렇게 봤어? / 다음엔 어떻게 해? / 나와 상대 바꾸기.
- **진행 표시**: 점 세 개가 통통 튀는 말풍선 + 단계 문구, 답이 오면 글자가 이어서 써진다.
- **플로팅 탭바**: 대화·기록·연습, 선택 탭은 연파랑 알약 + 채운 아이콘.

## 7. 사용성 규칙

- 터치 영역 최소 44×44px, 주요 행동은 화면 아래 1/3에.
- 첫 화면에서 **한 번의 탭으로** 사진 선택이 열린다 (입력창의 사진 버튼, `캡처로 분석`).
- 결과는 준비되는 대로 위에서부터 채운다. 가장 쓸모 있는 것(요약, 보낼 문장)을 먼저, 근거는 접어 둔다.
- 기다리는 시간(분석 5~15초)에는 무엇을 하는 중인지 계속 알려준다.
- 실패는 사용자 탓으로 쓰지 않고 다음 행동을 준다. ("글자를 읽지 못했어요. 더 선명한 캡처로 다시 올려 주세요")
- 모든 화면에 나가는 길이 있다. 닫을 수 없는 팝업, 뒤로가기를 막는 안내를 만들지 않는다.
- 문구는 토스 해요체, 비속어·과한 유행어 금지.
- 색만으로 의미를 전달하지 않는다(아이콘·라벨 병기). 글자 대비 4.5:1 이상.
- 움직임은 200~300ms, `prefers-reduced-motion`이면 끈다.

## 8. 하지 않는 것

- 다크 모드, 검은 배경 화면
- 글·버튼 뒤에 그라데이션 깔기 (그라데이션은 캐릭터 카드 바탕에만)
- 다른 서비스의 캐릭터·일러스트 가져오기
- 자체 상단 헤더, 자체 로고를 내비게이션 바에 넣기
- 사람을 색으로 낙인찍는 표현
