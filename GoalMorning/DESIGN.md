# GoalMorning 디자인 가이드

분위기: **따뜻하고, 조용하고, 고급스럽게.** 아침 햇살이 드는 서재에서 좋은 노트를 펼치는 느낌.
목표를 "할 일 목록"이 아니라 "소중한 다짐"처럼 대하는 앱.

> 참고 스킬: `.claude/skills/stageshow` (craft.md의 여백·글자·색·아이콘 원칙을 앱 UI에 맞게 옮김.
> 앱스토어 스크린샷·소개 페이지용 화면 일러스트를 만들 때는 이 스킬을 그대로 사용)

## 1. 폰트

| 용도 | 폰트 | 이유 |
|---|---|---|
| 제목 · 비전 문구 · 큰 숫자 | **마루 부리 (MaruBuri)** | 붓의 흐름이 살아있는 한글 명조. 잡지·책 같은 품격, 다짐 문장에 무게감 |
| 본문 · 버튼 · UI 전체 | **Pretendard** | 국내 앱 표준급 가독성, 굵기 단계가 많아 정돈된 위계 |

- 둘 다 **SIL Open Font License**: 앱에 넣어 배포해도 무료.
- 파일을 `assets/fonts/`에 넣고 `expo-font`로 불러온다 (인터넷 없이도 동작).
- 사용 굵기만 포함해 용량 절약: 마루 부리 Regular·SemiBold, Pretendard Regular·Medium·SemiBold.
- 명조는 **"마음에 닿는 문장"에만** 쓴다: 비전, "왜 중요한가", 화면 제목, 축하 문구. 버튼·목록·설정은 전부 Pretendard.

### 글자 크기

| 이름 | 폰트 / 크기 / 굵기 / 줄간격 | 쓰는 곳 |
|---|---|---|
| display | 마루 부리 30 / SemiBold / 1.3 | 아침 인사, 축하 화면 |
| title | 마루 부리 22 / SemiBold / 1.35 | 화면 제목, 비전 문구 |
| quote | 마루 부리 17 / Regular / 1.6 | "왜 중요한가", 오늘의 다짐 |
| body | Pretendard 16 / Regular / 1.5 | 본문, 목록 |
| label | Pretendard 14 / Medium / 1.4 | 버튼, 탭, 칩 |
| caption | Pretendard 12 / Regular / 1.4 | 날짜, 보조 설명 |

- 자간: 제목 -0.5%, 본문 0. 숫자는 Pretendard `tabular-nums`로 자리 고정.
- 시스템 글자 크기 설정을 따른다 (최대 1.3배까지 레이아웃이 깨지지 않게).

## 2. 색

종이처럼 따뜻한 아이보리 바탕 + 깊은 먹색 글자 + 아침 햇살 같은 **호박색(앰버) 포인트 하나**.

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| canvas | `#F7F3EC` | `#14120F` | 화면 바탕 |
| surface | `#FFFDF9` | `#1E1B17` | 카드 |
| raised | `#FFFFFF` | `#2A2621` | 시트, 팝업 (다크에선 그림자 대신 밝은 면으로 깊이) |
| line | `#E8E1D6` | `#38332C` | 구분선 (꼭 필요할 때만) |
| text-strong | `#1F1B16` | `#F4EFE7` | 제목 |
| text | `#4A4339` | `#CFC7BB` | 본문 |
| text-faint | `#8C8274` | `#8F8678` | 보조 글자 |
| accent | `#B8742A` | `#E0A15A` | 주요 버튼, 선택, 진행률 |
| accent-soft | `#F3E6D3` | `#3A2C1C` | 선택된 칩 배경 |
| success | `#5E8B6A` | `#86B592` | 완료 체크 |

- **포인트 색은 하나만.** 화면마다 강조는 한 곳 (보통 주요 버튼 하나).
- 상태 색(완료 초록)은 상태에만. 빨강은 쓰지 않는다 (죄책감 없는 앱).
- 테두리보다 **면 색 차이**로 구분. 장식용 그라데이션·글로우 금지 (아침 브리핑 상단의 아주 옅은 해돋이 톤 하나만 예외).

## 3. 여백과 모양

- 4의 배수 간격: 4 · 8 · 12 · 16 · 24 · 32 · 48
- 화면 좌우 여백 **24**, 카드 안쪽 여백 **20**, 목록 행 높이 최소 **52** (손가락 터치 44 이상)
- 모서리: 카드 20, 버튼·입력칸 14, 칩 999(알약형). 안쪽 모양 반경 = 바깥 반경 − 안쪽 여백
- 제목과 그 설명은 가깝게(4~6), 다음 덩어리와는 멀게(24 이상). 공간으로 묶는다
- 한 화면에 **큰 글자는 하나** (아침 인사 또는 비전 문구)
- 빈 공간은 실패가 아니라 쉼. 화면을 억지로 채우지 않는다

## 4. 아이콘 · 이미지

- 아이콘 세트 하나만: **Phosphor Icons** (`phosphor-react-native`), Regular 굵기, 20~24px로 통일
- 아이콘을 직접 그리지 않는다. **이모지는 아이콘 대신 쓰지 않는다** (기분 선택처럼 내용일 때만 허용)
- AI 기능이 생겨도 반짝이(✨)·보라색 금지. AI가 하는 일을 그대로 보여준다

## 5. 움직임

- 짧고 부드럽게: 200~300ms, ease-out. 튀는 바운스 없음
- 완료 체크: 체크가 그려지고 글자가 살짝 옅어짐 + 가벼운 진동(haptic)
- 목표 달성 축하: 화면 전체가 천천히 밝아지는 한 번의 순간. 폭죽 남발 금지
- 시스템 "동작 줄이기" 설정이면 애니메이션 끔

## 6. 문구 톤

- 존댓말, 짧게, 따뜻하게. 다그치지 않는다
  - O "오늘도 한 걸음이면 충분해요" / X "목표를 달성하지 못했습니다"
  - O "다시 와줘서 반가워요" / X "3일 연속 기록이 끊겼어요"
- 버튼은 동사로: "오늘 시작하기", "내일로 옮기기"

## 7. 점검 목록 (화면 만들 때마다)

- [ ] 눈이 처음 닿는 곳이 이 화면의 핵심인가?
- [ ] 강조 색이 한 곳에만 있는가?
- [ ] 명조는 마음에 닿는 문장에만 쓰였는가?
- [ ] 글자가 카드 가장자리에서 12 이상 떨어져 있는가? 요소끼리 1~3px로 아슬아슬하게 붙은 곳은 없는가?
- [ ] 다크 모드와 큰 글자 설정에서도 괜찮은가?
- [ ] 문구가 다그치지 않는가?
