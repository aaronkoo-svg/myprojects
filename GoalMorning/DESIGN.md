# GoalMorning 디자인 가이드 (v2, 애플 디자인 언어)

기준 자료: [`design/apple-reference.md`](design/apple-reference.md) (애플 웹사이트 디자인 분석).
그 원칙을 모바일 앱에 맞게 옮긴 것이 이 문서다. 코드 값은 `src/constants/theme.ts`.

**한 줄 요약:** UI는 물러서고 내 비전이 주인공이 된다. 회색 바탕 위 흰 카드, 비전은 어두운 무대(타일) 위에,
누를 수 있는 것은 모두 파란색 하나, 그림자와 장식 그라데이션은 없다.

## 1. 원칙

1. **강조색은 Action Blue 하나.** 버튼, 링크, 선택, 체크, 진행률 모두 파랑. 두 번째 강조색은 없다. 빨강·초록도 쓰지 않는다.
2. **그림자 없음.** 깊이는 면 색 차이로만 만든다 (회색 바탕 ↔ 흰 카드 ↔ 어두운 타일).
3. **밝음과 어둠의 교차.** 가장 중요한 한 가지(비전, 온보딩 첫 장면)는 어두운 타일에 올려 무대처럼 보이게 한다.
4. **큰 글자는 단단하게.** 제목일수록 자간을 좁힌다. 본문은 17px.
5. **누르는 것은 알약.** 버튼, 칩, 한 줄 입력칸은 완전한 알약 모양. 카드는 18 반경. 그 사이 값은 쓰지 않는다.
6. **누르면 살짝 작아진다** (scale 0.97). 색이 바뀌는 대신.

## 2. 글꼴

**Pretendard** 하나만 쓴다. SF Pro와 Apple SD Gothic Neo에 가장 가까운 무료 한글 글꼴이라 아이폰·안드로이드에서 같은 인상을 준다.
애플처럼 **300 / 400 / 600 / 700** 네 굵기만 쓰고 500은 쓰지 않는다.

| 이름 | 크기 / 굵기 / 줄높이 / 자간 | 쓰는 곳 |
|---|---|---|
| hero | 34 / 700 / 41 / -0.9 | 화면 큰 제목 (인사, "목표", "기록") |
| title | 28 / 600 / 34 / -0.6 | 비전 문장, 질문 |
| tagline | 21 / 600 / 27 / -0.4 | 섹션 제목 |
| lead | 21 / 300 / 31 / -0.3 | "왜 중요한가", 오늘의 다짐 (가볍고 여유 있게) |
| body | 17 / 400 / 25 / -0.374 | 본문, 버튼, 입력 |
| bodyStrong | 17 / 600 / 22 / -0.374 | 목록 제목, 강조 |
| caption | 14 / 400 / 20 / -0.224 | 설명, 칩 |
| captionStrong | 14 / 600 / 18 / -0.224 | 날짜, 작은 라벨 |
| fine | 12 / 400 / 16 / -0.12 | 아주 작은 안내 |

온보딩 첫 화면 제목만 40px, 기록의 큰 숫자만 64px로 키운다 (한 화면에 큰 것은 하나).

## 4. 모양과 여백

- 반경: 작은 도구 8, 카드·여러 줄 입력 18, 버튼·칩·한 줄 입력 알약(999)
- 여백: 4 · 8 · 12 · 17 · 24 · 32 · 48 · 64. 화면 좌우 20, 카드 안쪽 20
- 섹션 사이 32, 제목과 설명은 4로 붙인다
- 터치 영역 최소 44
- 목록은 카드 안에서 얇은 구분선으로 나눈다 (iOS 묶음 목록)

## 5. 부품

| 부품 | 모양 |
|---|---|
| 기본 버튼 | 파란 알약, 흰 글자 17px, 높이 50 |
| 보조 버튼 | 투명 알약 + 파란 1px 테두리, 파란 글자 |
| 텍스트 버튼 | 파란 글자만 (링크는 오른쪽에 › ) |
| 칩 | 흰 알약 + 옅은 테두리, 선택하면 파란 2px 테두리 |
| 입력칸 | 흰 알약 + 아주 옅은 테두리, 포커스 때 파란 2px 테두리 |
| 체크 | 미리알림 앱처럼 동그라미, 완료하면 파랗게 채움 |
| 확인창 | iOS 알림창: 가운데 글, 아래 나란한 "취소 / 확인" |
| 편집 화면 | iOS 시트: 왼쪽 "취소", 가운데 제목, 오른쪽 "저장" |
| 탭 바 | 바탕색 그대로 + 위쪽 얇은 선, 선택된 탭만 파랑 |

## 6. 아이콘

- **Phosphor Icons** 하나만, Regular 굵기 (탭 선택 시 Fill). 빈 화면 아이콘은 Light + 회색
- 직접 그리지 않는다. 이모지를 아이콘 대신 쓰지 않는다
- AI 기능이 생겨도 반짝이(✨)·보라색 금지

## 7. 문구 톤

- 존댓말, 짧게, 다그치지 않는다
  - O "오늘도 한 걸음이면 충분해요" / X "목표를 달성하지 못했습니다"
- 버튼은 동사로: "오늘 시작하기", "추가", "저장"
