# GoalMorning 플랜 (v2)

매일 아침 나의 미래 목표와 계획을 다시 떠올리게 하고, 오늘 할 일에 집중하게 도와주는 모바일 앱.

**핵심 원칙**
1. **아침 1분**: 알림을 누르고 1분 안에 오늘의 초점을 정하고 끝낼 수 있어야 한다.
2. **빈 화면 없음**: 처음 쓰는 사람도 예시와 질문을 따라가면 목표가 채워진다.
3. **죄책감 없음**: 며칠 빠져도 혼내지 않고 "다시 시작"을 쉽게 만든다.
4. **연결을 보여주기**: 오늘 할 일이 어떤 꿈으로 이어지는지 항상 보이게 한다.

## 결정된 방향 (인터뷰 결과)

| 항목 | 결정 |
|---|---|
| 플랫폼 | 아이폰 + 안드로이드 둘 다 |
| 리마인드 | 푸시 알림, 아침 브리핑, 짧은 체크인 (AI 코칭은 나중 단계) |
| 목표 구조 | 계층형: 미래 비전 → 장기 목표 → 단기 계획 → 오늘 할 일 |
| 사용자/저장 | 나 혼자, 폰에만 저장 (로그인·서버 없음) |
| 저녁 회고 | 넣기 (선택 사항으로) |
| 개발 | Claude가 대부분 개발, 설치·실행 방법은 쉽게 안내 |
| 분위기 | 따뜻하고 응원하는 느낌 |

## 기술 선택

- **Expo (React Native + TypeScript)**: 코드 하나로 아이폰·안드로이드 모두 지원
- **expo-sqlite**: 폰 안에 데이터 저장
- **expo-notifications**: 아침·저녁 로컬 알림 (서버 불필요)
- **expo-router**: 화면 이동
- **expo-sharing / expo-document-picker**: 백업 파일 내보내기·불러오기

## 목표 계층 구조

```
미래 비전 (5~10년 후 되고 싶은 모습, 1~3개)
└── 장기 목표 (1~3년)
    └── 단기 계획 (이번 달 / 이번 주)
        └── 오늘 할 일 (아침에 1~3개)
```

- 계층은 **권장일 뿐 강제하지 않는다**. 단기 계획만 있어도, 연결 안 된 할 일만 있어도 앱이 동작한다.
- 각 목표에는 **"왜 중요한가"** 한 줄을 적는다. 아침 브리핑에서 이 문장을 보여줘 동기를 다시 깨운다.
- 목표 상태: 진행 중 / 달성 🎉 / 보류 / 보관. 삭제보다 보관을 기본으로 둔다 (지난 목표도 기록).
- 장기 목표 진행률 = 연결된 단기 계획의 완료 비율 (자동 계산).

## 화면 구성

하단 탭 4개: **오늘 · 목표 · 기록 · 설정**

### 0. 첫 실행 온보딩 (약 3분, 언제든 건너뛰기 가능)
1. 앱 소개 1장 ("매일 아침 1분, 내 꿈을 다시 떠올려요")
2. "5년 후 어떤 하루를 보내고 싶나요?" → 비전 1개 (예시 문장 제공)
3. "그걸 위해 올해 꼭 이루고 싶은 것은?" → 장기 목표 1개
4. "이번 주에 할 수 있는 첫 걸음은?" → 단기 계획 1개
5. 아침·저녁 알림 시간 고르기 → 이유를 설명한 뒤 **알림 권한 요청**
6. 끝나면 바로 첫 아침 체크인 화면으로 이동

### 1. 오늘 탭 (시간대에 따라 바뀜)
- **아침 (체크인 전)**: 브리핑 + 체크인을 **한 화면**에서 처리
  - 인사 + 비전 한 줄 + "왜 중요한가" 한 줄 (매일 다른 목표가 돌아가며 나옴)
  - 어제 회고 한 줄 / 어제 못 끝낸 일 → "오늘로 가져오기" 버튼
  - 이번 주 단기 계획에서 **오늘 집중할 1~3가지 탭해서 선택** (직접 입력도 가능)
  - 오늘의 다짐 한 줄 (선택) → "오늘 시작하기" 버튼
- **낮 (체크인 후)**: 오늘의 1~3가지 체크리스트 + 각 항목이 어느 목표에 연결되는지 표시
- **저녁**: 상단에 "오늘 회고하기" 카드
- 상태 화면: 목표가 없을 때, 체크인을 놓쳤을 때, 오래 쉬었다 돌아왔을 때("다시 와줘서 반가워요")

### 2. 저녁 회고 (30초 목표, 전부 선택 사항)
- 오늘 할 일 체크 → 못 끝낸 일은 "내일로 / 단기 계획으로 되돌리기 / 버리기"
- 기분 이모지 1개
- 잘한 점 한 줄 (아쉬운 점은 접혀 있는 선택 칸)
- 회고를 놓쳤다면 다음 날 아침에 "어제 어땠어요?" 를 짧게 물어본다

### 3. 주간 돌아보기 (매주 일요일 저녁, 약 3분)
단기 계획이 오래되면 아침 브리핑도 의미가 없어지므로 꼭 필요하다.
- 이번 주 완료한 일 / 체크인 횟수 보기
- 단기 계획 정리: 완료 / 다음 주로 / 보관
- 다음 주 단기 계획 1~3개 세우기 (장기 목표에서 고르기)
- 한 달에 한 번: "비전과 장기 목표가 아직 나에게 맞나요?" 점검

### 4. 목표 탭
- 비전 → 장기 → 단기를 접고 펼 수 있는 트리
- 추가 · 수정 · 순서 변경 · 상태 변경 · 연결 바꾸기
- 목표 달성 시 축하 화면 🎉

### 5. 기록 탭
- 이번 달 체크인 달력 (점 찍기)
- **이번 주 체크인 수** 중심 표시 (예: "이번 주 5/7일"). 연속 일수는 보조로만 보여주고, 끊겨도 부정적인 문구 없음
- 완료한 할 일·달성한 목표 모아보기, 지난 회고 보기

### 6. 설정
- 아침·저녁 알림 시간 (**평일 / 주말 따로**), 요일별 끄기
- 주간 돌아보기 요일·시간
- 백업 내보내기 / 불러오기
- 글자 크기, 다크 모드 (시스템 따름)
- 앱 잠금 (Face ID / 지문, 선택)

## 알림 설계

| 알림 | 기본 시간 | 문구 예시 |
|---|---|---|
| 아침 | 평일 07:00 / 주말 09:00 | "좋은 아침이에요 ☀️ 오늘도 '{비전}'을 향해 한 걸음" |
| 저녁 | 21:30 | "오늘 하루 어땠어요? 30초면 충분해요" |
| 주간 | 일요일 20:00 | "이번 주도 수고했어요. 다음 주를 같이 그려볼까요?" |

- 문구는 여러 개를 돌려서 매번 다르게 (내 목표 이름을 넣어서)
- 이미 체크인했으면 그날 아침 알림 이후 추가 알림 없음, 회고 끝났으면 저녁 알림 생략
- 알림을 누르면 바로 해당 화면으로 이동
- 알림 권한을 거부했을 때: 앱 안에 안내 + 설정으로 가는 버튼

## 데이터 구조 (요약)

- `goals`: id, level(vision/long/short), parent_id(선택), title, why, period(주/월, 단기만), due_date, status, sort_order, created_at
- `tasks`: id, date, goal_id(선택), title, done, carried_from(가져온 날짜)
- `checkins`: date, intention, created_at
- `reviews`: date, mood, went_well, to_improve
- `weekly_reviews`: week_start, notes
- `settings`: 알림 시간들, 주간 돌아보기 시간, 앱 잠금 여부, 온보딩 완료 여부

## 데이터 안전 (폰에만 저장하므로 중요)

- 폰을 잃어버리거나 앱을 지우면 데이터가 사라진다 → **백업 내보내기/불러오기를 초기 단계에 넣는다**
- 주 1회 "백업할까요?" 가벼운 안내 (끌 수 있음)
- 나중에 원하면 iCloud / Google Drive 자동 백업 추가

## 개발 단계

매 단계가 끝날 때마다 폰에서 바로 써볼 수 있게 한다.

| 단계 | 내용 | 끝나면 할 수 있는 것 |
|---|---|---|
| 0 ✅ | Expo 프로젝트 세팅, 폰에서 실행하는 방법 확정, 디자인 기본(색·글꼴) | 빈 앱을 내 폰에서 열어보기 |
| 1 ✅ | 온보딩 + 목표 탭 + 오늘 탭(체크인·체크리스트) | **첫날부터 실제로 사용 가능한 최소 버전** |
| 1.5 ✅ | AI 목표 도우미: 윗단계만 적으면 AI(Claude)가 아랫단계 후보를 제안, 고른 것만 저장. 내 API 키 사용 | 비전 한 문장으로 계획까지 완성 |
| 2 | 아침·저녁 알림 + 백업 내보내기/불러오기 | 매일 아침 알림으로 루틴 시작, 데이터 안전 |
| 3 | 저녁 회고 + 못 끝낸 일 가져오기 + 다음 날 브리핑 반영 | 하루 루틴 완성 |
| 4 | 주간 돌아보기 + 기록 탭 | 목표가 낡지 않게 유지 |
| 5 | 디자인 다듬기, 축하 화면, 다크 모드, 글자 크기, 앱 잠금 | 계속 쓰고 싶은 완성도 |
| 나중 | AI 코칭 메시지, 주간 돌아보기 AI 제안, 홈 화면·잠금화면 위젯, 클라우드 백업, 앱스토어 배포 | |

## 직접 해야 하는 것

- 폰에 **Expo Go** 앱 설치 (앱스토어 / 플레이스토어)
- 1단계 이후 실제 비전·목표를 넣고 1주일 써보며 불편한 점 알려주기
- 정식 설치: 안드로이드는 APK로 바로 설치 가능, 아이폰은 Apple 개발자 계정(연 $99) 필요

## 검토 메모 (v1 → v2 변경 이유)

- 첫 실행 때 빈 화면 → **온보딩 추가**
- 브리핑과 체크인이 따로라 아침 단계가 많음 → **한 화면으로 합침**
- 단기 계획을 다시 세우는 흐름이 없어 금방 낡음 → **주간 돌아보기 추가**
- 못 끝낸 일 처리 방법 없음 → **내일로 가져오기**
- 연속 일수만 보면 하루 빠질 때 의욕이 꺾임 → **주간 횟수 중심 + 다시 시작 환영**
- 폰에만 저장인데 백업이 마지막 단계 → **2단계로 앞당김**
- 알림 권한을 언제 받을지 없음 → **온보딩에서 이유 설명 후 요청**, 거부 시 대처 추가
- 주말 기상 시간 차이 → **평일/주말 알림 시간 분리**
- 개인적인 내용이라 → **앱 잠금(선택)** 추가
- 목표 진행 상황이 안 보임 → **장기 목표 진행률 자동 계산**, 달성 축하

## AI 목표 도우미 (1.5단계)

- 흐름: 비전 → AI가 장기 목표 3개 제안 → 고른 목표마다 이번 주 계획 3개 제안 → 고른 것만 저장
- 들어가는 곳: 온보딩 2번째 질문의 "나머지는 AI에게 제안받기", 목표 탭의 "AI 제안" 링크, 설정 → AI 도우미
- 연결: 사용자 본인의 Anthropic API 키 (폰 보안 저장소에 보관). 모델 `claude-opus-5-5`, effort low, 구조화된 출력(JSON), 거절 시 서버 측 대체 모델(fallbacks: default)
- 전송되는 정보: 제안을 받을 때의 비전·목표 문장과 이미 있는 목표 이름만. 나머지 기록은 폰에만
- 코드: `src/lib/ai.ts`, `src/lib/ai-key.ts`, `src/app/suggest.tsx`, `src/app/ai-key.tsx`
- 나중에 다른 사람에게 배포할 때는 키를 서버에 두는 방식으로 바꾼다
