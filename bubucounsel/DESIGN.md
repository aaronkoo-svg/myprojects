# bubucounsel 디자인 시스템

Apple 스타일 DESIGN.md(`docs/reference/apple-DESIGN.md`)를 **토스 미니앱·모바일 한 손 사용**에 맞게 옮긴 문서입니다.
화면을 만들 때는 이 문서를 기준으로 합니다.

## 1. 원칙

1. **내용이 주인공, UI는 물러난다.** 장식용 그라데이션·테두리·그림자를 쓰지 않는다. 화면마다 주인공은 하나(대화 스크린샷, 판정 결과, 추천 문장).
2. **포인트 색은 하나.** 누를 수 있는 것은 전부 Action Blue, 그 외에는 무채색.
3. **넉넉한 여백과 큰 제목.** 제목은 굵고 자간을 좁히고, 본문은 편하게 읽히게 둔다.
4. **한 화면에 주요 버튼 하나.** 하단 고정 CTA 1개. 보조 행동은 텍스트 버튼.
5. **편들지 않는 톤.** 빨강·초록으로 사람을 "유죄/무죄" 칠하지 않는다. 색은 사람에게가 아니라 *말(발화)* 에 붙인다.

## 2. 토스 미니앱 제약 (디자인에 영향을 주는 것)

| 제약 | 적용 |
| --- | --- |
| 라이트 모드만 허용 | Apple 원본의 검은 타일(`#272729` 등)은 쓰지 않는다. 흰색·파치먼트 두 가지 바탕만 번갈아 쓴다. |
| 상단 내비게이션 바는 토스 공통 바 사용 | 자체 헤더·자체 뒤로가기 버튼을 만들지 않는다. 화면 제목은 본문 첫 줄의 큰 제목으로 표현. |
| 탭바는 토스 플로팅 탭바 형태, 2~5개 | 1단계는 탭 2개(홈·기록), 3단계에 연습 추가. 화면 하단에 떠 있는 알약 형태. |
| 진입 즉시 바텀시트 금지 | AI 고지·권한 안내는 화면 안 인라인 카드로. |
| 핀치 줌 비활성화 | 스크린샷 확대는 탭해서 전체 화면 보기로 제공. |
| 생성형 AI 결과 표시 의무 | 모든 AI 결과 카드에 `AI 분석` 배지. |

## 3. 색

```css
:root {
  /* 바탕 */
  --canvas: #ffffff;
  --canvas-parchment: #f5f5f7;   /* 섹션 구분, 카드 바탕 */
  --surface-pearl: #fafafc;

  /* 글자 */
  --ink: #1d1d1f;
  --ink-80: #333333;
  --ink-48: #7a7a7a;             /* 보조 설명, 캡션 */
  --hairline: #e0e0e0;
  --divider-soft: #f0f0f0;

  /* 포인트 (누를 수 있는 것 전용) */
  --primary: #0066cc;
  --primary-pressed: #0071e3;
  --on-primary: #ffffff;

  /* 의미색 — 발화 하이라이트에만, 옅은 바탕 + 진한 글자 */
  --tone-good-bg: #e8f5ee;  --tone-good-ink: #1b7a43;   /* 잘한 말 */
  --tone-care-bg: #fff4e0;  --tone-care-ink: #9a5b00;   /* 아쉬운 말 */
  --tone-hurt-bg: #fdecec;  --tone-hurt-ink: #b3261e;   /* 상처 주는 말 */
}
```

- 의미색은 넓은 면에 칠하지 않는다. 말풍선 왼쪽 3px 막대 + 옅은 바탕까지만.
- 나/상대 구분은 색이 아니라 **정렬(오른쪽/왼쪽)** 과 이름표로 한다.

## 4. 글꼴

**Pretendard Variable 하나만 쓴다.** (SIL OFL 1.1, 무료·상업 이용 가능, npm `pretendard`)
SF Pro는 Apple 기기 밖에서 쓸 수 없는 라이선스라 쓰지 않는다. Pretendard는 SF Pro와 Apple SD 산돌고딕 Neo의 비례를 따라 만든 글꼴이라 한글·영문·숫자를 섞어도 Apple 인상이 유지된다.

```css
font-family: "Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont,
             system-ui, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif;
font-feature-settings: "ss05", "tnum";  /* 숫자 폭 고정 */
word-break: keep-all;                   /* 한글 단어 중간 줄바꿈 방지 */
```

- 다이나믹 서브셋(woff2)으로 번들에 넣어 자체 호스팅한다. 외부 CDN에 의존하지 않는다.
- 감정이 실리는 인용문에만 쓸 보조 명조체(마루 부리, OFL)는 1차 범위에서 넣지 않는다. 글꼴이 하나일 때 더 고급스럽다.

| 역할 | 크기 / 줄높이 | 굵기 | 자간 |
| --- | --- | --- | --- |
| display (결과 한 줄 요약) | 32 / 1.15 | 700 | -0.02em |
| title-1 (화면 제목) | 26 / 1.2 | 700 | -0.02em |
| title-2 (섹션 제목) | 20 / 1.3 | 600 | -0.015em |
| body (본문) | 17 / 1.55 | 400 | -0.01em |
| body-strong | 17 / 1.55 | 600 | -0.01em |
| callout (말풍선, 추천 문장) | 16 / 1.5 | 500 | -0.01em |
| caption | 14 / 1.45 | 400 | -0.005em |
| fine-print (고지 문구) | 12 / 1.4 | 400 | 0 |

- 본문 최소 16px, 고지 문구도 12px 아래로 내리지 않는다.
- 굵기는 400·500·600·700 네 가지만.

## 5. 간격·모양

- 간격 단위: 4 · 8 · 12 · 16 · 24 · 32 · 48. 화면 좌우 여백 20px, 섹션 사이 32~48px.
- 모서리: 카드 18px, 입력창·작은 칩 12px, 버튼·배지·탭바는 완전한 알약(9999px).
- 그림자: 기본은 없음. 떠 있는 것(플로팅 탭바, 하단 CTA 바)에만 `0 4px 24px rgba(0,0,0,.08)` 하나.
- 구분은 선보다 바탕색 차이(흰색 ↔ 파치먼트)로 한다. 선이 필요하면 1px `--hairline`.

## 6. 컴포넌트

- **주 버튼**: 높이 54px, 알약, `--primary` 바탕, 17px/600. 하단 고정, 홈 인디케이터 safe area 반영. 누르면 `scale(.98)` + `--primary-pressed`.
- **보조 버튼**: 바탕 없는 파란 글자 또는 파치먼트 알약.
- **카드**: 파치먼트 바탕, 18px 모서리, 안쪽 여백 20px, 테두리·그림자 없음.
- **AI 배지**: 12px/600, 파치먼트 알약, `AI 분석`. 결과 카드 왼쪽 위에 항상.
- **말풍선**: 원본 대화를 다시 그릴 때 사용. 상대는 왼쪽 파치먼트, 나는 오른쪽 흰색+1px 선. 문제 발화에는 왼쪽 3px 의미색 막대.
- **추천 문장 카드**: 큰따옴표 없이 callout 글자, 아래에 `복사하기` 텍스트 버튼.
- **업로드 영역**: 점선 테두리 대신 파치먼트 큰 카드 + 중앙 아이콘 + 한 줄 안내. 선택 후에는 썸네일 가로 스크롤.
- **진행 표시**: 스피너 대신 단계 문구가 바뀌는 스켈레톤("대화를 읽고 있어요 → 흐름을 정리하고 있어요").
- **플로팅 탭바**: 화면 아래 16px 띄운 알약, 아이콘+라벨 2~3개, 선택 탭만 `--ink`, 나머지 `--ink-48`.

## 7. 사용성 규칙

- 터치 영역 최소 44×44px, 주요 행동은 화면 아래 1/3에.
- 첫 화면에서 **두 번의 탭 안에** 사진 선택까지 간다.
- 결과는 준비되는 대로 위에서부터 채운다. 가장 쓸모 있는 것(요약, 보낼 문장)을 먼저, 근거는 접어 둔다.
- 기다리는 시간(분석 5~15초)에는 무엇을 하는 중인지 계속 알려준다.
- 실패는 사용자 탓으로 쓰지 않고 다음 행동을 준다. ("글자를 읽지 못했어요. 더 선명한 캡처로 다시 올려 주세요")
- 모든 화면에 나가는 길이 있다. 닫을 수 없는 팝업, 뒤로가기를 막는 안내를 만들지 않는다.
- 문구는 토스 해요체, 비속어·과한 유행어 금지.
- 색만으로 의미를 전달하지 않는다(아이콘·라벨 병기). 글자 대비 4.5:1 이상.
- 움직임은 200~300ms, `prefers-reduced-motion`이면 끈다.

## 8. 하지 않는 것

- 다크 모드, 검은 배경 화면
- 포인트 색 두 가지 이상, 그라데이션 버튼
- 카드 테두리+그림자 동시 사용
- 자체 상단 헤더, 자체 로고를 내비게이션 바에 넣기
- 사람을 색으로 낙인찍는 표현(전체 화면 빨강 "유죄")
